## 説明文（4,000 文字まで）

```
サブネット計算、まだ紙とペンで解いていませんか？

NetTre は、ネットワーク資格（CCNA など）の勉強を「通勤中に片手で」続けるための問題演習アプリです。答えの数字を打てば、すぐに正解と解説。1問30秒、電車の1駅ぶんの時間が勉強時間に変わります。

◆ こんな人におすすめ
・CCNA など、ネットワーク資格の合格を目指している
・サブネット計算に時間がかかる、つい間違えてしまう
・パソコン向けの問題サイトは、スマホだと解きにくいと感じる
・インフラの仕事で、すぐ使える計算機がほしい

◆ 片手で、サクサク解ける
・答えは数字を入力するだけ。IP アドレスの問題では「.」付きのキーボードが自動で開きます
・「回答する」も「次へ」も、親指の届く画面の下半分に
・回答した瞬間に正誤と解説。迷う時間を減らします

◆ 苦手な問題が、自然に復習に回ってくる
・間違えた問題は翌日に、正解した問題は日をあけてもう一度（間隔反復）
・ホームを開けば「今日の復習」の数がひと目でわかります

◆ サブネット計算は、何度でも新しい問題
・ネットワークアドレス・ブロードキャストアドレス・ホスト数・サブネットマスク・最後のホストアドレスの問題を自動で作ります
・難易度は基礎・標準・応用の3段階。/8・/16・/24 の基本から、/17〜/30 の応用まで
・解説では、ブロックサイズを使った暗算のコツを毎回確認できます

◆ 現場でも使える5つの計算機
・CIDR 計算：ネットワーク、ブロードキャスト、ホストの範囲、ワイルドカードマスクを一度に表示
・サブネット分割：分割数かホスト数で等分した一覧
・VLSM 設計：部署ごとの必要台数から、無駄の少ないアドレスを自動で割り当て
・経路集約：まとめたルートと、余分に含まれてしまう範囲まで
・進数変換：10 進・2 進・16 進を並べて表示
どの計算機も「解き方」を表示でき、結果はタップでコピーできます。

◆ 成績で、弱点が見える
・分野ごと、サブネット計算ごとの正答率を表示します

◆ 安心して使える
・アカウント登録は不要。開いてすぐ始められます
・学習の記録は iPhone の中だけに保存。外部への送信も、広告もありません
・インターネット接続を使わないので、電波の弱い地下鉄でも使えます

※ 収録している問題はすべてオリジナルです。実際の試験問題ではありません。
※ Cisco および CCNA は Cisco Systems, Inc. の商標です。本アプリは Cisco Systems, Inc. とは関係ありません。
```

## 審査メモ（Review Notes）

```
NetTre is an offline study app for networking certifications (e.g. CCNA). No account or login is required, and the app does not request any permissions or use the network.

How to try it:
1. Tap "学習を始める" (Start) on the Home tab. Type a number with the on-screen keypad and tap "回答する" (Answer). The result and explanation appear; tap "次へ" (Next).
2. The second tab "計算" contains IP calculators (CIDR, subnet split, VLSM, route summarization, radix conversion). For example, enter 192.168.10.77 and 26 in "CIDR 計算".
3. Learning history is stored only on the device with SwiftData and can be deleted in Settings.

All questions are original content written for this app; none are copied from real exams or third-party materials.
```
