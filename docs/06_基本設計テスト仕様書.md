## 1. 方針

| 項目 | 内容 |
|---|---|
| 05 との分担 | 05 は型・関数・ViewModel を単独で確かめる。06 は本物の `QuestionRepository`・`SubnetQuestionGenerator`・`SessionBuilder`・`ReviewStore` を通し、**実際に保存され、別の画面の数字に反映されるか**を確かめる |
| 時刻と暦 | `AppEnvironment`（詳細設計 §12.1）の `now` を 1 日目 08:00（2026-10-18）から進める。暦は `Asia/Tokyo` |
| テスト用の問題データ | 05 §6 と同じ 20 問（`net-fund` 12・`net-access` 4・`ip-conn` 4）。正解が「0」の問題は入れない（詳細設計 §12.12）。乱数の seed は 42 |
| 保存 | 結合テストはメモリ上の ModelContainer。UI テストは §12.9 の起動引数で決める |
| UI テスト | XCUITest。起動引数（デバッグビルドだけ有効。詳細設計 §12.9）：`-uitest`（固定の日時・暦・seed・テスト用データ・メモリ上の履歴）、`-uitestPersistentStore`・`-uitestResetStore`・`-uitestFailModelContainer`・`-uitestBrokenQuestions`・`-uitestKeepDefaults`・`-uitestDay <n>` |
| 合格の基準 | 自動のケースはすべて合格。手動のケースは記録表に結果とスクリーンショットを残す |

### 1.1 標準の回答パターン（P1）

`.mixed` の 1 回目（手書き 5 → 自動生成 5。詳細設計 §12.4）を次のように答える。

| 順 | 問題 | 回答 |
|---|---|---|
| 1〜5 | `net-fund-0001`〜`0005` | 1・3・5 番目は正解、2・4 番目は不正解（「0」を入力） |
| 6〜10 | 自動生成（標準） | 6・7 番目は不正解（「0」）、8〜10 番目は正解（正解は `SubnetQuestionGenerator` から得る） |

P1 のあとの状態：AnswerLog 10 件（正解 6）、ReviewRecord 7 件（手書き 5・自動生成の不正解 2）。

## 2. 学習の流れ（基本設計 §5・§6）

| ID | 確かめること | 手順 | 期待する結果 | 方法 |
|---|---|---|---|---|
| IT-LF-01 | 1 回の学習が最後まで通る | 1 日目に `.mixed` を組み立て、QuizSessionViewModel で P1 のとおり答える | AnswerLog 10 件・ReviewRecord 7 件。どの記録も dueDate は 2 日目 00:00 | 自動 |
| IT-LF-02 | 間違えた問題が翌日の先頭に来る（FR-10・11） | 1 日目に `.domain(.networkAccess)` で 3 問だけ答え（すべて不正解）、中断する → 2 日目に `.mixed` を組み立てる | 先頭 3 問が `net-access-0001`・`0002`・`0003` の順（同じ dueDate は ID 順。§12.4） | 自動 |
| IT-LF-03 | 正解した問題の間隔が広がる（FR-10、D2） | 1 日目に `net-fund-0001` だけ正解 → 2 日目に出て正解 → 3・4・5 日目に復習の記録を見る | 2 日目に出る。3・4 日目は出ない。5 日目に出る（2 日目の正解で interval 3） | 自動 |
| IT-LF-04 | 自動生成問題の再現と卒業（FR-06、D1・D3） | 1 日目に自動生成問題 X を間違える → 2 日目に正解 → 3 日目に正解 | 2・3 日目に出る X は、1 日目と同じ ID・問題文・正解。3 日目の正解で記録が消え、4 日目以降は出ない | 自動 |
| IT-LF-05 | 中断しても回答が残る（FR-15） | 3 問答えて `quit` → 成績の集計を読む | AnswerLog 3 件。成績の回答数 3。結果画面の数も 3 | 自動 |
| IT-LF-06 | 問題を直しても履歴が続く（D4） | 1 日目に version 1 の `net-fund-0001` を正解 → 問題データを version 2 にして `QuestionRepository` を作り直す → 2 日目に正解 | 同じ記録が更新され、streak 2・interval 3・questionVersion 2・dueDate 5 日目 00:00 | 自動 |
| IT-LF-07 | 消した手書き問題の記録を飛ばす | IT-LF-02 の 1 日目のあと、`net-access-0002` を問題データから消す → 2 日目に `.mixed` | 異常終了せず、先頭は `net-access-0001`・`0003`。全体で 10 問 | 自動 |
| IT-LF-08 | 分野別の出題（FR-12） | `.domain(.networkAccess)` ／ `.domain(.ipServices)`（0 問）を組み立てる | `net-access` の 4 問だけ ／ 空。（0 問の分野は画面では「準備中」で押せないので、空の表示は 05 UT-VM-08 で確かめる） | 自動 |
| IT-LF-09 | サブネット計算ドリル（FR-05・07） | `.subnetDrill(.advanced)` で 10 問答える | 全問が難易度 3 の自動生成問題。プレフィックス長は 17〜30。正解は `subnet(fromId:)` の値と一致 | 自動 |
| IT-LF-10 | 成績の集計（FR-13、S-05） | P1 のあとに StatsViewModel を読む | 全体 10 問・60%、サブネット計算 5 問・60%、ネットワークの基礎 5 問・60%、ほかの分野は「まだ回答していません」、今日解いた 10、今日の復習 0 | 自動 |
| IT-LF-11 | ホームの数字が日付で変わる（FR-11・13） | P1 のあと、2 日目 08:00 で HomeViewModel を読む | 今日の復習 7、今日解いた問題 0 | 自動 |
| IT-LF-12 | 学習履歴のリセット（FR-14） | P1 のあと `deleteAll` → Home・Stats の ViewModel を読み直す | 初めて起動したときと同じ状態（今日の復習 0、成績は「問題を解くと…」）。2 日目に組み立てても復習は 0 | 自動 |
| IT-LF-13 | 分野選択の数字（S-02） | IT-LF-02 の 1 日目のあと、2 日目 08:00 で `DomainListViewModel` を読む | `net-access` の行：収録 4 問・復習 3・正答率 0%。`net-fund` の行：収録 12 問・復習 0・正答率「―」 | 自動 |
