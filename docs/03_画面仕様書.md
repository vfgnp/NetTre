## 0. 全画面に共通する決まり

| 項目 | 決まり |
|---|---|
| 向き | 縦向きのみ |
| 画面の下部 | タブバー（学習／計算／成績／設定）。出題画面（S-03）だけはタブバーを隠して全画面にする |
| 片手操作 | よく使うボタンは画面下半分に置く。タップできる部分の高さは 56pt 以上（標準の 44pt より大きくする） |
| 文字 | 標準の文字スタイルを使い、Dynamic Type で大きくしても欠けない（はみ出す場合はスクロールさせる） |
| 色 | ライト・ダークの両方に対応。正誤は色だけで区別せず、記号（✓／✗）と文字も併せて出す |
| 触覚フィードバック | 正解・不正解のときに軽い振動（成功／エラー）を返す |
| 文言 | 「です・ます」調。ボタンは動詞で短く（「次へ」「回答する」） |
| 権限 | どの画面でも OS の権限を求めない |

## S-01 ホーム

**目的**：すぐに学習を始められるようにする。今日の復習の量が一目でわかる。

```
┌──────────────────────────┐
│ ネトレ                    │
│                          │
│ ┌──────────────────────┐ │
│ │ 今日の復習            │ │
│ │      12 問            │ │ ← ①
│ │ 今日解いた問題  8 問   │ │ ← ②
│ └──────────────────────┘ │
│                          │
│                          │
│ ┌──────────────────────┐ │
│ │    分野を選ぶ    ＞   │ │ ← ③
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │    学習を始める       │ │ ← ④（いちばん目立たせる）
│ └──────────────────────┘ │
├──────────────────────────┤
│ 学習 │ 計算 │ 成績 │ 設定 │
└──────────────────────────┘
```

| No | 項目 | 内容 |
|---|---|---|
| ① | 今日の復習 | 出す日が今日以前の問題の数（すべての分野） |
| ② | 今日解いた問題 | 今日の 0:00 以降に回答した数 |
| ③ | 分野を選ぶ | S-02 へ進む |
| ④ | 学習を始める | 出題範囲「おまかせ」で S-03 を開く（復習が先、足りない分は新しい問題） |

| 状態 | 表示 |
|---|---|
| 初めて起動したとき（履歴なし） | ①は「0 問」の代わりに「まずは1回、解いてみましょう」と表示 |
| 復習が 0 問 | ①に「今日の復習は終わりました」と表示。④はそのまま使える（新しい問題を出す） |

## S-02 分野選択

**目的**：出題範囲を選ぶ。

```
┌──────────────────────────┐
│ ＜ 戻る    分野を選ぶ      │
│                          │
│ サブネット計算ドリル        │
│ ┌──────────────────────┐ │
│ │ [基礎][標準][応用]     │ │ ← ①
│ │ 始める          ＞    │ │ ← ②
│ └──────────────────────┘ │
│                          │
│ 分野                      │
│ ネットワークの基礎   82% ＞ │ ← ③
│   30問 ・ 復習 3問         │
│ ネットワークアクセス 60% ＞ │
│   12問 ・ 復習 0問         │
│ IP 接続            ―  ＞ │
│ IP サービス       準備中   │ ← ④
│ …                        │
├──────────────────────────┤
│ 学習 │ 計算 │ 成績 │ 設定 │
└──────────────────────────┘
```

| No | 項目 | 内容 |
|---|---|---|
| ① | 難易度 | 基礎／標準／応用から選ぶ。初期値は「標準」。最後に選んだものを覚えておく |
| ② | 始める | 出題範囲「サブネット計算ドリル」と選んだ難易度で S-03 を開く |
| ③ | 分野の行 | 分野名、正答率（その分野の手書き問題の全回答。未回答なら「―」）、収録問題数、今日の復習数（その分野の手書き問題だけ。自動生成問題の復習はホームと成績の数にだけ入る）。タップでその分野の S-03 を開く |
| ④ | 準備中 | 収録問題が 0 問の分野。グレーで表示し、タップできない |

- 分野は要件定義書 §4.1 の順に並べる。
- サブネット計算ドリルを上に置く。MVP では問題数がいちばん多く、よく使うと見込むため。

## S-03 出題

**目的**：1問ずつ、答えの数字を自分で入力して解き、すぐに正誤と解説を確かめる。

回答はすべて入力式（要件定義 FR-02。選択式はない）。この画面には「回答前」と「回答後」の2つの状態がある。画面は切り替えず、同じ画面の中で表示を変える。

### S-03a 回答前

```
┌──────────────────────────┐
│ ✕          3 / 10        │ ← ① ②
│ ━━━━━━━━━━──────────── │ ← ③
│ ネットワークの基礎・標準 [復習]│ ← ④
│                          │
│ 192.168.10.77/26 が所属す │ ← ⑤
│ るネットワークアドレスを答え │
│ よ。                      │
│                          │
│ 回答                      │
│ ┌──────────────────────┐ │
│ │ 192.168.10.64         │ │ ← ⑥
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │       回答する         │ │ ← ⑦（キーボードのすぐ上）
│ └──────────────────────┘ │
│ ［数字キーボード（「.」付き）］│
└──────────────────────────┘
```

| No | 項目 | 内容 |
|---|---|---|
| ① | 中断（✕） | 学習をやめて S-04 へ。回答はその都度保存しているので、確認のダイアログは出さない。誤って押しにくいよう、あえて画面の左上に置く。VoiceOver では「学習を中断する」と読む |
| ② | 進み具合 | 「今の問題 / 全体の問題数」 |
| ③ | 進捗バー | 進み具合の割合 |
| ④ | 問題の情報 | 分野の表示名・難易度。復習の問題には「復習」の印を付ける |
| ⑤ | 問題文 | 長いときは問題文の部分だけスクロールする |
| ⑥ | 入力欄 | 画面を開いたら入力欄を選んだ状態にし、キーボードを出す（タップせずにすぐ打てる）。キーボードは正解の文字で決める：数字だけ → 数字のキーボード、数字と「.」だけ → 「.」付きの数字キーボード（iOS 標準の `.decimalPad`。「.」は左下のキー）。地域設定によって左下のキーが「,」になる端末でも、「,」は「.」とみなす（基本設計 §6.3）。IP アドレスなどは等幅の書体で表示する |
| ⑦ | 回答する | キーボードのすぐ上に置き、親指で押せるようにする。何か入力するまで押せない。数字のキーボードには改行キーがないため、回答はこのボタンで行う |

### S-03b 回答後

```
┌──────────────────────────┐
│ ✕          3 / 10        │
│ ━━━━━━━━━━──────────── │
│ ┌──────────────────────┐ │
│ │ ✗ 不正解               │ │ ← ⑧
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │ あなたの回答 192.168.10.0 │ │ ← ⑨
│ │ 正解        192.168.10.64│ │
│ └──────────────────────┘ │
│ 解説                      │ ← ⑩（ここだけスクロール）
│ /26 のサブネットマスクは   │
│ 255.255.255.192。…       │
│ 暗算のコツ: …             │
│ 計算機で確かめる      ＞   │ ← ⑫
│ ┌──────────────────────┐ │
│ │        次へ           │ │ ← ⑪
│ └──────────────────────┘ │
└──────────────────────────┘
```

| No | 項目 | 内容 |
|---|---|---|
| ⑧ | 正誤 | 「✓ 正解」または「✗ 不正解」。触覚フィードバックを返す。回答したらキーボードを閉じる |
| ⑨ | あなたの回答と正解 | 2行で並べる。不正解のときは「あなたの回答」に ✗、「正解」に ✓ を付ける（色と記号の両方で示す）。正解のときは「正解」の行だけでもよい |
| ⑩ | 解説 | 問題の解説（Markdown の太字・箇条書きに対応）。長いときはこの部分だけスクロールする |
| ⑪ | 次へ | 次の問題へ。最後の問題のときは「結果を見る」と表示し、S-04 へ進む。画面の下端（親指の届く位置）に置く。次の問題では入力欄が選ばれた状態でキーボードが出る |
| ⑫ | 計算機で確かめる | サブネット問題のときだけ、解説の下に出す。問題の IP アドレスとプレフィックス長を入れた S-08 CIDR 計算を**シート**で開く。閉じると解説に戻る（FR-23、基本設計 D10） |

- 回答後は入力欄を編集できないようにする（回答のやり直しはできない）。
- 回答した時点で学習履歴に保存する（基本設計 §8、NFR-09）。

## S-04 学習の結果

**目的**：今回の成果を見せ、間違えた問題を振り返れるようにする。

```
┌──────────────────────────┐
│          おつかれさまでした  │
│                          │
│         7 / 10 問 正解     │ ← ①
│                          │
│ 間違えた問題               │
│ ✗ /27 のホスト数は…    ＞  │ ← ②
│ ✗ 802.1Q トランク…    ＞  │
│ ✗ 192.168.3.200/28 …  ＞  │
│                          │
│ 間違えた問題は明日また出ます │ ← ③
│ ┌──────────────────────┐ │
│ │    もう1回学習する     │ │ ← ④
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │    ホームに戻る        │ │ ← ⑤
│ └──────────────────────┘ │
└──────────────────────────┘
```

| No | 項目 | 内容 |
|---|---|---|
| ① | 正解数 | 「正解数 / 回答した数」。中断したときは、回答した分だけで数える |
| ② | 間違えた問題 | 問題文の書き出し（1行）。タップで、その問題の回答後の状態（S-03b と同じ表示）を見られる。全問正解なら「全問正解です」と表示 |
| ③ | 案内 | 間違えた問題があるときだけ表示 |
| ④ | もう1回学習する | 同じ出題範囲で、新しく S-03 を開く |
| ⑤ | ホームに戻る | S-01 へ（出題範囲がサブネット計算ドリル・分野別でも S-01 に戻る） |

- 1問も回答せずに中断したときは、この画面を出さずに元の画面へ戻る。

## S-05 成績

**目的**：学習の進み具合と、苦手な分野を知る。

```
┌──────────────────────────┐
│ 成績                      │
│ ┌──────────┐┌──────────┐ │
│ │ 回答数    ││ 正答率    │ │ ← ①
│ │  248 問   ││  74%     │ │
│ └──────────┘└──────────┘ │
│ ┌──────────┐┌──────────┐ │
│ │ 今日の復習 ││ 今日解いた │ │
│ │  12 問    ││  8 問     │ │
│ └──────────┘└──────────┘ │
│                          │
│ 分野別                    │
│ サブネット計算  ▓▓▓▓▓░ 81% │ ← ②
│   120問                   │
│ ネットワークの基礎 ▓▓▓░ 62% │
│   60問                    │
│ …                        │
├──────────────────────────┤
│ 学習 │ 計算 │ 成績 │ 設定 │
└──────────────────────────┘
```

| No | 項目 | 内容 |
|---|---|---|
| ① | 全体の数字 | 回答数・正答率（全期間）、今日の復習数、今日解いた数 |
| ② | 分野別 | サブネット計算（自動生成問題）と6分野それぞれの、回答数と正答率。正答率は横棒と数字の両方で示す。回答が 0 の分野は「まだ回答していません」 |

- 正答率は「正解した回答の数 ÷ 回答の数」（同じ問題を何度解いても、それぞれ数える）。
- 自動生成のサブネット問題は分野としては「ネットワークの基礎」に属するが、成績では「サブネット計算」として分けて出す（v1.0 で確定）。

| 状態 | 表示 |
|---|---|
| 履歴なし | 「問題を解くと、ここに成績が表示されます」 |

## 計算機に共通する決まり（S-07〜S-12）

| 項目 | 決まり |
|---|---|
| 配置 | 入力欄を上、結果を下に置く。入力が変わるたびに結果を更新する（計算ボタンは置かない。NFR-13） |
| キーボード | IP アドレス・マスク・プレフィックス長の欄は「.」付きの数字キーボード（iOS 標準。「,」が出る地域設定でも「.」とみなす）。数字のキーボードには「/」がないため、**IP アドレスとプレフィックス長は別の欄**にする。`192.168.10.77/26` のように 1 つにまとめた文字を貼り付けたときは、2 つの欄に分けて入れる |
| プレフィックス長の欄 | `26` と `255.255.255.192` のどちらでも入力できる。欄の横に −／＋ ボタンを置き、1 ずつ変えられる |
| 誤った入力 | 欄の下に「✗ 第3オクテットが 256 です（0〜255）」のように、記号と文で示す。結果欄は空にする |
| 結果の値 | 等幅の書体で表示する。各行の右にコピーボタンを置き、行の長押しでもコピーできる。コピーしたら「コピーしました」と短く表示する（FR-24） |
| 解き方 | 結果の下に「解き方」を折りたたんで置く。開くと計算の過程を 1〜3 行で示す（FR-22） |
| 入力の保持 | 入力はアプリを閉じるまで画面ごとに残す。保存はしない（U-09） |

## S-08 CIDR 計算

**目的**：IP アドレスとプレフィックス長から、ネットワークの情報を一度に知る（FR-17）。

```
┌──────────────────────────┐
│ ＜ 計算     CIDR 計算      │
│ IP アドレス                │
│ ┌──────────────────────┐ │
│ │ 192.168.10.77         │ │ ← ①
│ └──────────────────────┘ │
│ プレフィックス長またはマスク   │
│ ┌──────────────┐ [−][＋] │ ← ②
│ │ 26            │         │
│ └──────────────┘         │
│ ネットワーク  192.168.10.64 ⧉│ ← ③
│ ブロードキャスト 192.168.10.127⧉│
│ サブネットマスク 255.255.255.192│
│ ワイルドカード  0.0.0.63      │
│ ホストの範囲  .65 〜 .126     │
│ 使えるホスト数 62（総数 64）  │
│ 2 進数  …00001010.01|001101 │ ← ④
│ 種別    プライベート         │
│ ▸ 解き方                   │ ← ⑤
└──────────────────────────┘
```

| No | 項目 | 内容 |
|---|---|---|
| ① | IP アドレス | 「.」付きの数字キーボード。`/26` 付きで貼り付けたら②に分けて入れる |
| ② | プレフィックス長 | `0`〜`32` またはサブネットマスク。−／＋ で 1 ずつ変えられる |
| ③ | 結果 | ネットワークアドレス、ブロードキャストアドレス、サブネットマスク、ワイルドカードマスク、ホストの範囲（最初〜最後）、使えるホスト数とアドレスの総数、アドレスの種別。各行にコピーボタン |
| ④ | 2 進数 | 32 ビットをオクテットごとに区切り、ネットワーク部とホスト部の境目に区切り線を入れて、ホスト部を薄い色で示す |
| ⑤ | 解き方 | 区切りが入るオクテット → ブロックサイズ → 何番目の倍数か、の順に示す（FR-22） |

- S-03 回答後の「計算機で確かめる」から開いたときは、シートとして表示し、左上を「閉じる」にする。①②には問題の値が入っている（FR-23）。
- `/31` は「使えるホスト数 2（ポイントツーポイント用）」、`/32` は「1 台のホスト」と示す。

## S-09 サブネット分割

**目的**：ネットワークを等分したときのサブネットの一覧を出す（FR-18）。

```
┌──────────────────────────┐
│ ＜ 計算    サブネット分割    │
│ ネットワーク  [192.168.10.0] / [24] │ ← ①
│ 分け方 [分割数｜ホスト数]     │ ← ②
│ ┌──────────────┐         │
│ │ 4             │         │ ← ③
│ └──────────────┘         │
│ /26 ・ 1 サブネット 62 台 ・ 4 件│ ← ④
│ ┌──────────────────────┐ │
│ │ 1 192.168.10.0/26     │ │ ← ⑤
│ │   .1 〜 .62  BC .63   │ │
│ │ 2 192.168.10.64/26    │ │
│ │ …                    │ │
│ └──────────────────────┘ │
│ ▸ 解き方                   │
└──────────────────────────┘
```

| No | 項目 | 内容 |
|---|---|---|
| ① | ネットワーク | IP アドレスとプレフィックス長の 2 つの欄（共通の決まり） |
| ② | 分け方 | 「分割数」と「ホスト数」の切り替え |
| ③ | 数 | 分割数、または 1 サブネットに必要なホスト数。数字のキーボード |
| ④ | 概要 | 分割後のプレフィックス長、1 サブネットの使えるホスト数、件数。分割数が 2 の累乗でないときは「5 分割 → 8 分割になります」と添える |
| ⑤ | 一覧 | 番号、CIDR、ホストの範囲、ブロードキャスト。行の長押しで CIDR をコピー。**先頭 256 件まで**表示し、超えるときは「全 ◯ 件のうち先頭 256 件」と示す（D6） |

## S-10 VLSM 設計

**目的**：用途ごとの必要ホスト数から、無駄の少ないサブネットを割り当てる（FR-19）。

```
┌──────────────────────────┐
│ ＜ 計算      VLSM 設計     │
│ 親ネットワーク [192.168.10.0] / [24]│ ← ①
│ 用途             必要ホスト数 │
│ [営業部        ] [ 50 ] ⊖ │ ← ②
│ [開発部        ] [ 25 ] ⊖ │
│ [拠点間リンク   ] [  2 ] ⊖ │
│ ＋ 用途を追加               │ ← ③
│ ┌──────────────────────┐ │
│ │ 営業部  .0/26   62/50  │ │ ← ④
│ │ 開発部  .64/27  30/25  │ │
│ │ 拠点間  .96/30   2/2   │ │
│ │ 空き    .100/30 ほか   │ │ ← ⑤
│ └──────────────────────┘ │
└──────────────────────────┘
```

| No | 項目 | 内容 |
|---|---|---|
| ① | 親ネットワーク | IP アドレスとプレフィックス長の 2 つの欄 |
| ② | 用途の行 | 用途名（通常のキーボード）と必要ホスト数（数字のキーボード）。⊖ で行を消す |
| ③ | 用途を追加 | 行を 1 つ足す。**50 件まで**（D7）。上限に達したらボタンを押せなくし、理由を添える |
| ④ | 割り当て結果 | 必要ホスト数の多い順に、用途名・CIDR・ホストの範囲・「使える数 / 必要数」。行の長押しで CIDR をコピー |
| ⑤ | 空き | 使わずに残った範囲を CIDR のまとまりで示す |

- 入りきらないときは、結果の代わりに「✗ 親ネットワークに ◯ アドレス足りません」と示す。

## S-11 経路集約

**目的**：複数のネットワークをまとめる集約ルートを求める（FR-20）。

```
┌──────────────────────────┐
│ ＜ 計算       経路集約      │
│ [192.168.0.0 ] / [24] ⊖  │ ← ①
│ [192.168.1.0 ] / [24] ⊖  │
│ [192.168.2.0 ] / [24] ⊖  │
│ ＋ ネットワークを追加         │ ← ②
│ 集約ルート                  │
│ 192.168.0.0/22        ⧉  │ ← ③
│ 余分に含まれる範囲            │
│ 192.168.3.0/24            │ ← ④
│ ▸ 解き方                   │
└──────────────────────────┘
```

| No | 項目 | 内容 |
|---|---|---|
| ① | ネットワークの行 | IP アドレスとプレフィックス長の 2 つの欄。⊖ で行を消す。ホスト部が 0 でないときは「ホスト部を 0 にして扱いました」と添える |
| ② | ネットワークを追加 | 行を 1 つ足す。**32 件まで**（D8） |
| ③ | 集約ルート | すべてを含む最小の集約ルート。コピーできる |
| ④ | 余分に含まれる範囲 | 集約によって入力以外に含まれてしまう範囲。なければ「ありません（ちょうど集約できます）」 |

## S-12 進数変換

**目的**：IPv4 アドレスやマスクを 10 進・2 進・16 進で見比べる（FR-21）。

```
┌──────────────────────────┐
│ ＜ 計算       進数変換      │
│ ┌──────────────────────┐ │
│ │ 255.255.255.192       │ │ ← ①
│ └──────────────────────┘ │
│ 10 進として読みました         │ ← ②
│ 10 進  255.255.255.192  ⧉ │ ← ③
│  2 進  11111111.11111111. │
│        11111111.11000000 ⧉│
│ 16 進  FF.FF.FF.C0       ⧉ │
└──────────────────────────┘
```

| No | 項目 | 内容 |
|---|---|---|
| ① | 入力 | 英数字のキーボード（16 進の a〜f と `0x` を打てるようにする） |
| ② | 読み取った進数 | 自動で見分けた結果を示す（D9：`0x`・a〜f → 16 進、0 と 1 だけで 8 けた × 4 → 2 進、それ以外 → 10 進） |
| ③ | 結果 | 10 進・2 進・16 進の 3 行。2 進は 8 けた、16 進は 2 けたでオクテットごとに区切る。各行にコピーボタン |
