NetTre

通勤中に片手で解ける、ネットワーク資格（CCNA 対策）のドリル

できること

  • 答えの数字を入力して解く問題演習。間違えた問題は翌日に、正解した問題は間隔を広げてもう一度出ます。
  • サブネット計算の問題を自動で作るドリル（基礎・標準・応用）。
  • CIDR 計算・サブネット分割・VLSM 設計・経路集約・進数変換の計算機。解き方も表示します。

お問い合わせ

不具合の報告・問題の誤りの指摘・ご要望は、GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。

GitHub Issues を開く

問題の誤りを報告するときは、問題文と、アプリが表示した正解を書いてください。

よくある質問

学習の記録はどこに保存されますか？
お使いの iPhone の中だけに保存します。外部に送ることはありません。

学習の記録を消したい
アプリの「設定」→「学習履歴を削除する」で消せます。アプリを削除しても消えます。

機種を変えたら記録は引き継げますか？
今のところ引き継げません（記録は端末の中だけに保存しているため）。
