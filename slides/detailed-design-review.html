QUESTION MODEL

Question モデルの変更

引き継ぎ時
kind: QuestionKind // single など domain: String choices: [Choice] answer: [String] isCorrect(_ response: [String])
→
新しい形
domain: Domain // enum 6 分野 answer: String // 正解は 1 つ isGenerated: Bool // ID から判定 keyboard: AnswerKeyboard isCorrect(_ input: String)

Domain は表示名（「ネットワークの基礎」）と ID の略称（net-fund）を持つ。isCorrect は両方を AnswerNormalizer で整えて比べる

D11手書き問題の JSON の形を変える

kind・choices をなくし、answer を配列から文字列にする（例 "answer": "110"）
引き継いだサンプルは実装時にこの形へ直し、選択式の 2 問は数字で答える問題に作り直す

学習の組み立て

復習を古い順に最大 10 問 → 残りを新しい問題で埋める。削除された手書き問題の記録は飛ばす

出題範囲復習に使う記録新しい問題の埋め方

サブネット計算ドリル選んだ難易度の自動生成問題選んだ難易度の自動生成問題だけ

CALCULATORS 1 / 4

計算機の土台

Subnet（/0〜/32 に拡張）
マスク・ワイルドカード・ネットワーク・ブロードキャスト
アドレスの総数 2^(32−p)、使えるホスト数
/0〜/30：総数 − 2 ／ /31：2 ／ /32：1
最初と最後のホスト
/31：ネットワークとブロードキャスト ／ /32：そのアドレス
計算は UInt32・UInt64 の整数演算。範囲を確かめてから足す
入力の誤り（IPv4InputParser）
「4 つの数をピリオドで区切って入力してください」
「第3オクテットが 256 です（0〜255）」
「プレフィックス長は 0〜32 です」
「マスクの 1 が連続していません」

010 は 10 として受け付ける（8 進数とみなさない）
a.b.c.d/n を貼り付けたら 2 つの欄に分ける

CALCULATORS 2 / 4

CIDR 計算とサブネット分割

計算きまり
CIDR 計算Subnet の各値と、アドレスの種別、解き方を返す
種別の判定の順ループバック 127/8 → プライベート 10/8・172.16/12・192.168/16 → リンクローカル 169.254/16
→ 共有アドレス 100.64/10 → マルチキャスト 224/4 → 予約 240/4・0/8 → それ以外はグローバル
分割数 n で分ける新しい長さ ＝ p ＋ ⌈log2 n⌉。32 を超えたら誤り
2 の累乗でなければ切り上げた数を示す（5 分割 → 8 分割）
ホスト数 h で分けるh ＋ 2 以上の最小の 2 の累乗のブロック。親より大きいブロックが要るなら誤り
一覧件数 ＝ 2^(新しい長さ − p)。親のネットワークからブロックずつ進めて作る。先頭 256 件まで（D6）

CALCULATORS 3 / 4

VLSM 設計と経路集約

VLSM 設計
1　各用途のブロック ＝ h ＋ 2 以上の最小の 2 の累乗
2　合計が親を超えたら「◯ アドレス足りません」
3　必要数の多い順（同じなら入力順）に先頭から割り当てる
4　残りの範囲を CIDR のまとまりに分けて「空き」に
経路集約
1　入力のホスト部を 0 にそろえる
2　最小のアドレスと最大のブロードキャストの
XOR の先頭の 0 の数 ＝ 集約の長さ
3　集約の範囲から入力を除いた隙間を
CIDR のまとまりに分けて「余分な範囲」に
共通処理 CIDRBlocks　範囲 [start, end] を、start の境界に合う最大のブロックから順に切り出す（両方の計算機で使う）

進数変換と解き方

進数の見分け方（D9）　上から順に当てはめる
1 → 16 進
0x で始まる・a〜f を含む
区切りありは 1〜2 けた × 4
区切りなしは 8 けた
→
2 → 2 進
0 と 1 だけで 8 けた × 4
または区切りなしの 32 けた
→
3 → 10 進
それ以外
IPv4 の入力読み取りで読む
解き方の文（CIDR 計算）

区切りのオクテット i ＝ p ÷ 8、ブロックサイズ b ＝ 256 ÷ 2^(p mod 8)
p が 8 の倍数なら「オクテットの境目なので後ろを 0 にする」の 1 文

例 192.168.10.77/26　区切りは第 4 オクテット。ブロックサイズは 64
77 は 64 の 1 倍〜2 倍の間なので、ネットワークは .64
